# 思凡邮箱群发工具

基于miko邮箱域名API开发的邮件群发工具，支持批量邮箱管理和邮件群发功能。

## 功能特性

### 🔐 用户认证
- 支持网站地址、用户名、密码登录
- 安全的会话管理
- 自动登录状态保持

### 📧 邮箱管理
- 查看邮箱列表和状态
- 创建单个邮箱
- 批量创建邮箱
- 获取邮箱密码
- 删除邮箱

### 📨 邮件群发
- 支持多收件人群发
- 可设置发送批次和延时
- 实时发送进度显示
- 发送状态统计
- 发送历史记录

### ⚙️ 发送设置
- 可配置默认发送参数
- 邮件模板管理
- 系统信息查看
- 设置持久化保存

## 安装要求

### Python环境
- Python 3.7+
- PyQt5 5.15.9
- requests 2.31.0

### 安装依赖
```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 启动程序
```bash
python main.py
```

### 2. 登录系统
- 输入miko邮箱系统的服务器地址（如：http://localhost:8080）
- 输入用户名和密码
- 点击登录

### 3. 管理邮箱
- 在"邮箱账号"选项卡中查看现有邮箱
- 可以创建单个或批量创建邮箱
- 支持获取邮箱密码和删除操作

### 4. 发送邮件
- 在"发送邮件"选项卡中编辑邮件
- 选择发件人邮箱
- 输入收件人列表（每行一个邮箱）
- 编写邮件主题和内容
- 设置发送参数（批次大小、延时等）
- 点击开始发送

### 5. 配置设置
- 在"发送设置"选项卡中配置默认参数
- 管理邮件模板
- 查看系统信息

## 界面说明

### 主界面
- 顶部显示当前登录用户信息
- 三个主要选项卡：邮箱账号、发送邮件、发送设置
- 底部状态栏显示操作状态

### 邮箱账号选项卡
- 左侧：邮箱列表表格，显示邮箱地址、域名、状态等信息
- 右侧：邮箱操作面板
  - 创建单个邮箱：输入前缀、选择域名、设置密码
  - 批量创建邮箱：输入前缀列表、选择域名
  - 邮箱操作：获取密码、删除邮箱

### 发送邮件选项卡
- 左侧：邮件编辑面板
  - 邮件信息：发件人、收件人、主题
  - 邮件内容：富文本编辑器
  - 发送设置：批次大小、延时设置
- 右侧：发送状态面板
  - 发送进度条和状态显示
  - 发送统计信息
  - 发送历史记录

### 发送设置选项卡
- 服务器设置：配置API服务器地址
- 默认发送设置：批次大小、延时、自动保存等
- 邮件模板：预设模板管理和应用
- 系统信息：用户信息和统计数据

## API接口

本工具基于miko邮箱系统的REST API开发，主要使用以下接口：

- `POST /api/login` - 用户登录
- `GET /api/mailboxes` - 获取邮箱列表
- `POST /api/mailboxes` - 创建邮箱
- `POST /api/mailboxes/batch` - 批量创建邮箱
- `GET /api/mailboxes/:id/password` - 获取邮箱密码
- `DELETE /api/mailboxes/:id` - 删除邮箱
- `POST /api/emails/send` - 发送邮件
- `GET /api/domains/available` - 获取可用域名

## 配置文件

程序会在运行目录生成 `config.json` 配置文件，保存用户设置：

```json
{
  "server_url": "http://localhost:8080",
  "default_batch_size": 1,
  "default_delay": 0,
  "auto_save_draft": true,
  "templates": {
    "默认模板": {
      "subject": "默认邮件主题",
      "content": "这是默认邮件内容模板。"
    }
  }
}
```

## 注意事项

1. **网络连接**：确保能够访问miko邮箱系统的API服务器
2. **权限要求**：需要有效的用户账号和相应的邮箱操作权限
3. **发送限制**：遵守邮件服务商的发送频率限制
4. **数据安全**：邮箱密码等敏感信息仅在内存中临时存储
5. **批量操作**：大批量操作时建议设置适当的延时避免服务器压力

## 故障排除

### 登录失败
- 检查服务器地址是否正确
- 确认用户名和密码是否正确
- 检查网络连接是否正常

### 邮箱创建失败
- 确认邮箱前缀格式是否符合要求
- 检查域名是否可用
- 确认用户权限是否足够

### 邮件发送失败
- 检查发件人邮箱是否有效
- 确认收件人邮箱格式是否正确
- 检查邮件内容是否符合规范
