# 思凡邮箱群发工具 - 使用说明

## 快速开始

### 1. 运行程序
**Windows用户：**
- 双击 `run.bat` 文件启动程序
- 或者在命令行中运行：`python main.py`

**Linux/Mac用户：**
- 在终端中运行：`./run.sh`
- 或者运行：`python3 main.py`

### 2. 登录系统
1. 程序启动后会弹出登录对话框
2. 输入miko邮箱系统的服务器地址（例如：`http://localhost:8080`）
3. 输入您的用户名和密码
4. 点击"登录"按钮

## 主要功能

### 邮箱账号管理

#### 查看邮箱列表
- 登录成功后，在"邮箱账号"选项卡可以看到您的所有邮箱
- 表格显示邮箱地址、域名、状态、邮件数量等信息
- 点击"刷新"按钮可以更新邮箱列表

#### 创建单个邮箱
1. 在右侧"创建单个邮箱"区域
2. 输入邮箱前缀（如：user123）
3. 选择域名（从下拉列表中选择）
4. 输入邮箱密码
5. 点击"创建邮箱"按钮

#### 批量创建邮箱
1. 在右侧"批量创建邮箱"区域
2. 在文本框中输入邮箱前缀列表，每行一个：
   ```
   user1
   user2
   user3
   ```
3. 选择域名
4. 点击"批量创建"按钮

#### 邮箱操作
- **获取密码**：选中邮箱后点击"获取密码"按钮
- **删除邮箱**：选中邮箱后点击"删除邮箱"按钮（注意：此操作不可恢复）

### 邮件群发

#### 编写邮件
1. 切换到"发送邮件"选项卡
2. 选择发件人邮箱（从您的邮箱列表中选择）
3. 输入收件人列表，每行一个邮箱地址：
   ```
   user1@example.com
   user2@example.com
   user3@example.com
   ```
4. 输入邮件主题
5. 编写邮件内容

#### 发送设置
- **每批发送数量**：设置每次发送的邮件数量（建议1-10）
- **批次间延时**：设置每批发送之间的延时时间（秒）

#### 开始发送
1. 检查所有信息无误后，点击"开始发送"按钮
2. 确认发送信息后点击"是"
3. 右侧会显示发送进度和状态
4. 发送过程中可以点击"停止发送"按钮中止

#### 发送监控
- **发送进度**：实时显示发送进度条和状态信息
- **发送统计**：显示总数、成功数、失败数
- **发送历史**：记录每次发送的历史信息

### 发送设置

#### 服务器设置
- 配置miko邮箱系统的服务器地址
- 修改后需要重新登录

#### 默认发送设置
- **默认批次大小**：设置默认的每批发送数量
- **默认延时**：设置默认的批次间延时
- **自动保存草稿**：是否自动保存邮件草稿

#### 邮件模板
1. **选择模板**：从下拉列表选择预设模板
2. **加载模板**：点击"加载模板"按钮载入选中的模板
3. **编辑模板**：修改模板主题和内容
4. **保存模板**：保存当前编辑的模板
5. **应用模板**：将模板应用到发送页面

#### 系统信息
- 显示当前用户信息
- 显示邮箱和邮件统计信息
- 点击"刷新信息"更新数据

## 使用技巧

### 1. 批量操作
- 创建邮箱时，建议一次不超过50个，避免服务器压力
- 发送邮件时，设置适当的批次大小和延时，避免被识别为垃圾邮件

### 2. 邮件内容
- 邮件主题要简洁明了，避免使用过多特殊字符
- 邮件内容要规范，避免包含敏感词汇
- 可以使用模板功能提高效率

### 3. 发送策略
- 大量发送时建议分批进行，每批间隔一定时间
- 监控发送状态，如果失败率过高应暂停检查原因
- 遵守邮件服务商的发送规范和限制

### 4. 数据管理
- 定期备份重要的邮箱账号信息
- 及时清理不需要的邮箱，释放资源
- 保存常用的邮件模板，提高工作效率

## 常见问题

### Q: 登录失败怎么办？
A: 
1. 检查服务器地址是否正确
2. 确认用户名和密码是否正确
3. 检查网络连接是否正常
4. 确认miko邮箱系统服务是否正常运行

### Q: 邮箱创建失败？
A:
1. 检查邮箱前缀格式是否符合要求（只能包含字母、数字、点、横线、下划线）
2. 确认选择的域名是否可用
3. 检查用户权限是否足够
4. 避免创建重复的邮箱

### Q: 邮件发送失败？
A:
1. 检查发件人邮箱是否有效且已激活
2. 确认收件人邮箱格式是否正确
3. 检查邮件内容是否包含敏感词汇
4. 确认网络连接稳定
5. 检查是否超出发送频率限制

### Q: 程序运行错误？
A:
1. 确认Python版本是否为3.7+
2. 检查依赖包是否正确安装
3. 查看错误信息，根据提示解决
4. 重启程序尝试

## 注意事项

1. **合规使用**：请遵守相关法律法规，不要发送垃圾邮件或违法内容
2. **频率控制**：合理控制发送频率，避免对服务器造成压力
3. **数据安全**：妥善保管账号信息，不要泄露给他人
4. **备份重要数据**：定期备份重要的邮箱和模板数据
5. **及时更新**：关注程序更新，及时升级到最新版本
